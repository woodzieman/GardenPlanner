# GardenPlanner — TestFlight Build & Upload Guide

## Quick Start (5 Steps)

### Step 1: Set Your Team ID in Xcode (Required)
1. Open `GardenPlanner/GardenPlanner.xcodeproj` in Xcode
2. Select the **GardenPlanner** target
3. Go to **Signing & Capabilities**
4. ✅ Check **Automatically manage signing**
5. Select your team from the dropdown (must be an Apple Developer Program member)
6. Set Bundle Identifier to: `com.josephwoods.GardenPlanner`

**How to find your Team ID:**
- Apple Developer Portal: https://developer.apple.com/account → upper right corner
- Or Xcode: Preferences → Accounts → select your account → Team ID shown next to name

### Step 2: Verify Setup
```bash
cd fastlane
./scripts/setup_certs.sh
```

### Step 3: Install Dependencies (if not already done)
```bash
cd fastlane
bundle install
```

### Step 4: Build the IPA
**Option A — Export IPA for manual upload (no API key needed):**
```bash
cd fastlane
bundle exec fastlane export_ipa
```
This creates `fastlane/output/GardenPlanner.ipa`

**Option B — Direct TestFlight upload (requires API key):**
First configure `fastlane/app_store_connect_api_key.json` with your API key details, then:
```bash
cd fastlane
bundle exec fastlane beta
```

### Step 5: Upload to TestFlight

**For exported IPA (Option A above):**

1. **Via Apple Developer Portal (drag-and-drop):**
   - Go to https://appstoreconnect.apple.com
   - My Apps → 3D Garden Planner → TestFlight tab
   - Click the **+** (plus) button on the Builds section
   - Drag and drop `fastlane/output/GardenPlanner.ipa` into the upload area

2. **Via Transporter App (Apple's recommended tool):**
   - Download Transporter: https://apps.apple.com/us/app/transporter/id1450874784
   - Open Transporter → drag `fastlane/output/GardenPlanner.ipa` onto it
   - Select "3D Garden Planner" as the app
   - Click Upload

## Certificate & Provisioning Profile Requirements

### What You Need
1. **Apple Developer Program Membership** ($99/year)
   - Must be Active (not Expired or Revoked)

2. **Distribution Certificate**
   - Created automatically when you enable "Automatically manage signing"
   - Located in Keychain Access under "Signing Certificates"

3. **App ID**
   - Bundle ID: `com.josephwoods.GardenPlanner`
   - Capabilities needed: Camera, Local Network

4. **App Record in App Store Connect**
   - Must be created at https://appstoreconnect.apple.com
   - Name: "3D Garden Planner"
   - Bundle ID: `com.josephwoods.GardenPlanner`

5. **Provisioning Profile** (auto-generated by Xcode)
   - Type: App Store or Ad Hoc
   - Xcode creates this automatically when signing is enabled

### Certificate Verification
Run the setup script to check everything:
```bash
cd fastlane
./scripts/setup_certs.sh
```

## Understanding the Build Options

| Lane | API Key Needed | Output | Use Case |
|------|---------------|--------|----------|
| `export_ipa` | No | `fastlane/output/GardenPlanner.ipa` | Drag-and-drop upload to Apple |
| `beta` | Yes | Uploads directly to TestFlight | Automated CI/CD pipeline |
| `simulator` | No | `.app` for simulator only | Local testing (no device) |

## Troubleshooting

### "Signer's certificate expired" or "Certificate invalid"
- Your distribution certificate has expired
- Go to Apple Developer → Certificates → Create a new distribution certificate
- Or: Xcode will auto-generate one when you select your team

### "No provisioning profile found"
- Xcode generates this automatically with "Automatically manage signing" enabled
- Make sure your bundle ID matches exactly: `com.josephwoods.GardenPlanner`

### "Team ID is wrong or doesn't match"
- Make sure the Team ID in Xcode matches your Apple Developer account
- You can find it in the Apple Developer Portal (upper right)

### "IPA upload failed: invalid archive"
- Make sure you're building with **Release** configuration
- Make sure the bundle ID matches the app record in App Store Connect
- Make sure the app record exists before uploading

### "fastlane not found"
- Run `bundle install` in the `fastlane/` directory

### "Xcode command line tools not set"
- Run: `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer`

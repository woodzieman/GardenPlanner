## One Command to Build (After Setting Team ID)

```bash
# Team ID is already set (VDWDUNC9R2). Open the project once in Xcode so it
# can register the app with your account / auto-generate signing, then run:
./build_for_testflight.sh
```

The script will output an `.ipa` file to `fastlane/output/GardenPlanner.ipa`.

## Drag-and-Drop Upload

After the build succeeds:

1. Go to **https://appstoreconnect.apple.com**
2. My Apps → **3D Garden Planner** → **TestFlight** tab
3. Click the **+** button in the Builds section
4. **Drag and drop** `fastlane/output/GardenPlanner.ipa`

Or use Apple's **Transporter** app (free, from the Mac App Store).

## Troubleshooting

**"Team ID is empty"** → Open Xcode, set your team in Signing & Capabilities

**"Signer's certificate expired"** → Xcode auto-generates a new one when you select your team

**"No provisioning profile"** → Xcode auto-generates when signing is enabled

**"Build failed — project invalid"** → Project.pbxproj may be corrupted; open in Xcode and save

## Fastlane (Optional — for CI/automation)

```bash
cd fastlane
bundle install        # First time only
bundle exec fastlane export_ipa    # Build .ipa (no API key needed)
bundle exec fastlane beta          # Direct TestFlight upload (needs API key)
bundle exec fastlane simulator     # For local simulator testing
```
